Why Aion is Not "Just Another Profiler": Traditional trace visualizers like the QNX Momentics System Profiler or Eclipse Trace Compass are descriptive—they render millions of raw kernel events on a timeline and leave the human engineer to manually hunt for milliseconds of delay, cross-reference hex mutex/semaphore addresses (sync_p), track dynamic server priorities across MsgSend boundaries, and guess why a deadline was missed. Aion is a causal verification and root-cause analysis (RCA) engine. Instead of asking you to eyeball a Gantt chart, Aion evaluates declarative TOML timing and scheduling contracts, automatically constructs multi-hop Causal Graphs that prove why a violation occurred—linking high-priority victims to low-priority resource holders and medium-priority CPU preemptors with exact trace line numbers and cycle timestamps—prescribes the exact QNX API fix, and returns a deterministic exit code (0 = PASS, 1 = FAIL, 4 = INCONCLUSIVE) to block real-time regressions in CI/CD before they ever reach hardware.
